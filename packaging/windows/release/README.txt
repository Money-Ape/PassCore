Overview
--------
PassCore is an offline-first desktop vault that securely stores passwords and personal images using modern encryption.

Everything stays on your device. No cloud account, no data collection, and no internet connection is required to access your vault.

Features
--------
Security
• AES-GCM authenticated encryption
• Argon2id key derivation
• Master password protection
• Distributed blob storage
• SHA-256 integrity verification
• Automatic vault locking
• Local encrypted storage

Password Vault
• Secure password management
• Cryptographically secure password generator
• Search records (Ctrl + F)
• Autosave & save-before-exit protection

Image Vault
• Encrypted image storage
• Album management
• Responsive gallery
• Timeline view
• Thumbnail caching
• Multi-image selection
• Rename & delete images
• Integrity verification

Backup & Recovery
• Automatic backups
• Backup restore
• Backup retention management

Customization
• Runtime theme switching
• 13 built-in themes

Privacy
-------
PassCore is completely offline-first.

Your passwords, images, and backups remain on your computer.
PassCore never uploads your data or communicates with external servers.

Project Status
--------------
Alpha Release (v0.4.6)

PassCore is under active development. While the application includes modern cryptography and integrity verification, it is still considered experimental.

Please keep regular backups of important vault data.
