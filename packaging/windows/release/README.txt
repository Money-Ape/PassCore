## Overview

PassCore is an offline-first password manager focused on local encrypted vault storage, integrity verification, and user-controlled backups.

## Features

• AES-GCM authenticated encryption
• Argon2id key derivation
• Distributed blob storage architecture
• Vault Health diagnostics
• Password Generator
• Search Records
• Automatic backups
• Import / Export support
• Runtime theme switching
• 13 built-in themes
• Auto-lock protection

## Storage

PassCore stores vault data locally and does not upload data to external servers.

## Project Status

Alpha Release (v0.4.2)

This software is actively developed and should be considered experimental. Always maintain backups of important data.
